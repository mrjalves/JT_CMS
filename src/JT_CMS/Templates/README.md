# Templates

Modelos de site importados pelo **Setup**. Cada template contém:

| Item | Descrição |
|---|---|
| `site.json` | Nome, layouts, papéis, configurações e tema |
| `manifest.json` | Definições de plugins disponíveis |
| `Layouts/` | Layouts HTML (`DefaultLayout`, `EditLayout`, `SingleLayout`) |
| `Blocks/` | Blocos prontos por categoria (Hero, CTA, FAQ, Feature, Footer, Headers, Pricing, Teams, Testimonials...) |
| `Pages/` | Páginas (`.html` estáticas e `.sbn` Scriban) numeradas por ordem |
| `Files/` | CSS, JS e imagens do site |

| Template | Descrição |
|---|---|
| [Blank](Blank/README.md) | Base vazia com layouts e blocos |
| [Default](Default/README.md) | Site padrão com exemplos e blog |
| [Portfolio](Portfolio/README.md) | Portfólio (sobre, projetos, contato) |
