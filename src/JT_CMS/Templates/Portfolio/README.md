# Template Portfolio

Modelo de site de portfólio profissional para **Desenvolvedor de Software & IA**.

## 🚀 Destaques e Estrutura

- **Home (`/`)**: Hero section com foto de perfil, apresentação profissional, chamada para ação (CTA), download direto do currículo (PDF), redes sociais (GitHub, LinkedIn, Credly, WhatsApp) e vitrine de projetos em destaque.
- **Sobre Mim (`/about`)**: Perfil profissional completo, foto com moldura moderna, habilidades com badges de proficiência, experiências profissionais reais (ERP, sustentação, microsserviços), premiações em Hackathons e certificações.
- **Projetos (`/projects` e `/projects/detail`)**: Catálogo dos projetos públicos do GitHub (`JT_CMS`, `JT_Finance`, `JT_Food`, `JTech_AppManager`, `JT_Portifolio`, `AI Pipelines com Python`) com tags de tecnologias, descrições detalhadas e links diretos para os repositórios.
- **Contato (`/contact`)**: Canais diretos de comunicação (E-mail, WhatsApp, LinkedIn, GitHub) e formulário integrado ao plugin de contato.
- **Arquivos & Mídia (`Files/`)**: Imagem de perfil (`images/julio-cesar.png`), currículo para download (`resume.pdf`), assets de estilo (`css/app.css` com suporte a glassmorphism e dark mode).
