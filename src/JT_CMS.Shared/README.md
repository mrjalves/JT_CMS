# JT_CMS.Shared

Tipos compartilhados entre backend e frontend.

- `Exceptions/` – `AppException`, `AppError`, `ExceptionCodes`, `AppApiClientException`.
- `AssetDetail` – descrição de ativos (CSS/JS) de plugins.
- `ViewState` – estado de visualização (View/Edit).
- `DictionaryJsonConverter` – serialização de dicionários.
