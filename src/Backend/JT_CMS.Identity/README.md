# JT_CMS.Identity

Integração com **ASP.NET Core Identity**. Implementa o `UserStore` sobre os repositórios do CMS, dividido em arquivos parciais por interface:

`IUserPasswordStore`, `IUserEmailStore`, `IUserLockoutStore`, `IUserLoginStore`, `IUserClaimStore`, `IUserPhoneNumberStore`, `IUserSecurityStampStore`, `IUserTwoFactorStore`, `IUserAuthenticatorKeyStore`, `IUserTwoFactorRecoveryCodeStore`, `IUserAuthenticationTokenStore`, `IQueryableUserStore`.

Também contém `IdentityResultExtensions`.
