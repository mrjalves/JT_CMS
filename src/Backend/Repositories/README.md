# Repositories

Camada de persistência com **múltiplos bancos suportados**. O banco é escolhido em `appsettings.json`:

```json
"Database": "LiteDb"
```

| Valor | Projeto |
|---|---|
| `litedb` | [JT_CMS.Repositories.LiteDb](JT_CMS.Repositories.LiteDb/README.md) |
| `mongodb` | [JT_CMS.Repositories.MongoDB](JT_CMS.Repositories.MongoDB/README.md) |
| `sqlite` | [JT_CMS.Repositories.EFCore.Sqlite](JT_CMS.Repositories.EFCore.Sqlite/README.md) |
| `sqlserver` | [JT_CMS.Repositories.EFCore.SqlServer](JT_CMS.Repositories.EFCore.SqlServer/README.md) |
| `mysql` | [JT_CMS.Repositories.EFCore.MySql](JT_CMS.Repositories.EFCore.MySql/README.md) |
| `postgresql` | [JT_CMS.Repositories.EFCore.PostgreSQL](JT_CMS.Repositories.EFCore.PostgreSQL/README.md) |

Projetos de apoio: [Abstractions](JT_CMS.Repositories.Abstractions/README.md), [EFCore](JT_CMS.Repositories.EFCore/README.md) (base comum) e [Caching](JT_CMS.Repositories.Caching/README.md).
