# JT_CMS.Repositories.MongoDB

Persistência em **MongoDB**.

```json
{
  "Database": "MongoDB",
  "ConnectionStrings": { "DefaultConnection": "mongodb://localhost:27017/JT_CMS" }
}
```

Principais arquivos: `MongoDBContext.cs`, `MongoDBOptions.cs`, `MongoDBServiceExtensions.cs` (`AddMongoDbRepositories`) e um repositório por entidade.
