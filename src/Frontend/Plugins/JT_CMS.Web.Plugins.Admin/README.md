# JT_CMS.Web.Plugins.Admin

Telas administrativas do CMS (plugins `Locked`).

| Pasta | Funcionalidade |
|---|---|
| `Auth/` | Login, registro e recuperação de senha |
| `SiteManagement/` | Sites |
| `PageManagement/` | Páginas |
| `LayoutManagement/` | Layouts |
| `BlockManagement/` | Blocos |
| `ContentTypeManagement/` | Tipos de conteúdo (campos: Boolean, Date, MultiFile, MultiSelect, Number, Select, SingleFile, String) e conteúdos |
| `FileManagement/` | Pastas e arquivos |
| `PluginDefinitionManagement/` | Definições de plugins |
| `UserManagement/`, `RoleManagement/` | Usuários e papéis |
| `ApiTokenManagement/` | Tokens de API |
| `GlobalSettingManagement/` | Configurações globais |
| `Componenets/` | Componentes compartilhados das telas |
