# JT_CMS.Web.Plugins.Base

Fundação para os plugins.

- `BasePlugin` / `BaseEditPlugin` – ciclo de vida e acesso ao contexto/conteúdo.
- `ActionNames` – nomes das ações de plugin.
- `Components/Buttons`, `Components/FileManagement`, `Components/FormRichTextEditor` – componentes reutilizáveis.
- `Resources/` – recursos compartilhados.
