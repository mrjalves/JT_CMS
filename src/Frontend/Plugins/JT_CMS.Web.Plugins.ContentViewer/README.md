# JT_CMS.Web.Plugins.ContentViewer

Exibe **conteúdos dinâmicos** criados a partir de Content Types (blogs, projetos...).

- `ContentList` – listagem de conteúdos (View/Edit).
- `ContentDetail` – página de detalhe de um conteúdo (View/Edit).
