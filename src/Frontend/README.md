# Frontend

Interface em **Blazor** do JT_CMS: renderização das páginas, editor visual (Site Builder), biblioteca de componentes e plugins.

| Projeto | Descrição |
|---|---|
| [JT_CMS.Web.UI](JT_CMS.Web.UI/README.md) | Aplicação Blazor, Site Builder e renderização dinâmica |
| [JT_CMS.Web.UI.Components](JT_CMS.Web.UI.Components/README.md) | Biblioteca de componentes (Flowbite) |
| [JT_CMS.Web.UI.TailwindStyleBuilder](JT_CMS.Web.UI.TailwindStyleBuilder/README.md) | Geração de CSS Tailwind dinâmico |
| [JT_CMS.Web.ApiClients](JT_CMS.Web.ApiClients/README.md) | Clientes HTTP da API (NSwag) |
| [Plugins](Plugins/README.md) | Plugins de conteúdo e administração |
