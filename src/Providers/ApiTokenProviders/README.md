# ApiTokenProviders

Providers de **tokens de API**, divididos em dois projetos:

| Projeto | Papel |
|---|---|
| [JT_CMS.Providers.ApiTokenProviders.Abstractions](JT_CMS.Providers.ApiTokenProviders.Abstractions/README.md) | Interfaces/contratos |
| [JT_CMS.Providers.ApiTokenProviders](JT_CMS.Providers.ApiTokenProviders/README.md) | Implementação padrão |

Para criar outra implementação, crie um novo projeto referenciando o projeto `.Abstractions` e registre-o no `Program.cs` do host.
