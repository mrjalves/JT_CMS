# MessageBusProviders

Providers de **mensageria**, divididos em dois projetos:

| Projeto | Papel |
|---|---|
| [JT_CMS.Providers.MessageBusProviders.Abstractions](JT_CMS.Providers.MessageBusProviders.Abstractions/README.md) | Interfaces/contratos |
| [JT_CMS.Providers.MessageBusProviders](JT_CMS.Providers.MessageBusProviders/README.md) | Implementação padrão |

Para criar outra implementação, crie um novo projeto referenciando o projeto `.Abstractions` e registre-o no `Program.cs` do host.
