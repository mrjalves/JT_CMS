# CacheProviders

Providers de **cache**, divididos em dois projetos:

| Projeto | Papel |
|---|---|
| [JT_CMS.Providers.CacheProviders.Abstractions](JT_CMS.Providers.CacheProviders.Abstractions/README.md) | Interfaces/contratos |
| [JT_CMS.Providers.CacheProviders](JT_CMS.Providers.CacheProviders/README.md) | Implementação padrão |

Para criar outra implementação, crie um novo projeto referenciando o projeto `.Abstractions` e registre-o no `Program.cs` do host.
